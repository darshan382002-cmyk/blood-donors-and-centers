
# 🩸 Blood Donors and Centers Dashboard | Power BI

This repository contains an **interactive Power BI dashboard** for analyzing blood donor data and blood center insights.

## 📝 Report Tabs

### 1️⃣ Blood Donors and Centers
Includes key performance indicators (KPIs) such as:
- 🩸 New and Returning Blood Donors
- 🔝 Top N Donors and Centers
- 🔻 Bottom N Donors and Centers
- 📊 Key Donor and Center Insights

### 2️⃣ Cohort Analysis
- 📈 Visual cohort diagram to analyze donor trends and patterns over time.

## 🎯 Purpose
To explore donor data, identify trends, and support data-driven insights for blood donation and center analysis.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
